Arranging neurons side by side yields a **layer**; composing layers yields a
network. A fully-connected layer maps an input vector to an output vector by means
of a weight **matrix** $W$ and a bias **vector** $\mathbf{b}$:

$$
\mathbf{z}^{(\ell)} = W^{(\ell)} \mathbf{a}^{(\ell-1)} + \mathbf{b}^{(\ell)},
\qquad
\mathbf{a}^{(\ell)} = \sigma\!\left(\mathbf{z}^{(\ell)}\right)
$$

with $\mathbf{a}^{(0)} = \mathbf{x}$. Evaluating this recurrence from the input
layer to the output layer constitutes the **forward pass**.

## Activation functions

Three activation functions are in common use:

$$
\operatorname{sigmoid}(z) = \frac{1}{1 + e^{-z}}, \qquad
\tanh(z) = \frac{e^{z} - e^{-z}}{e^{z} + e^{-z}}, \qquad
\operatorname{ReLU}(z) = \max(0, z)
$$

z = np.linspace(-6, 6, 300)

fig, ax = plt.subplots(figsize=(6, 3.2))
ax.plot(z, sigmoid, label="sigmoid")
ax.plot(z, np.tanh(z), label="tanh")
ax.plot(z, relu, label="ReLU")
ax.axhline(0, color="0.7", lw=0.8); ax.axvline(0, color="0.7", lw=0.8)
ax.legend(); ax.set_title("Three activation functions")
ax.grid(alpha=0.25)

print("NumPy", np.__version__, "— sigmoid(0) =", sigmoid[len(z)//2].round(3))
