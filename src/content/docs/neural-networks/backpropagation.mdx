Backpropagation is the chain rule, applied with systematic bookkeeping. The
network terminates in a scalar **loss** $L$, and we require $\dfrac{\partial
L}{\partial \theta}$ for every parameter $\theta$. Backpropagation computes all of
these derivatives in a single backward sweep.

The key identity is the following: if a node $v$ feeds into nodes $u_1, \dots,
u_k$, then

$$
\frac{\partial L}{\partial v}
= \sum_{j=1}^{k} \frac{\partial L}{\partial u_j}\,\frac{\partial u_j}{\partial v}.
$$

Each node requires only its **local** derivative $\partial u_j / \partial v$ and
the gradient propagating back from above. Multiplication and summation constitute
the entire algorithm.

## The flow of values and gradients

Consider a single neuron with a squared-error loss, depicted as a **computational
graph**. Pressing **run** sweeps the forward pass (values, left→right) followed by
the backward pass (gradients, right→left). Dragging any input then updates every
value *and* gradient in real time.

<ComputeGraph client:visible />

The gradient at each leaf — $w$, $x$, $b$ — is precisely what gradient descent
requires in order to adjust that parameter. Observe that $\partial L/\partial n$
and $\partial L/\partial b$ are equal: an **add** node copies the upstream gradient
to both inputs. A **multiply** node ($n = w\cdot x$) routes the gradient to each
input scaled by the *other* input, which is why $\partial L/\partial w = \partial
L/\partial n \cdot x$.

## A complete network, one step at a time

The single neuron above isolates the mechanism; a network merely repeats it. The
visualization below trains a genuine **2 → 3 → 1** network — two inputs, a hidden
layer of three $\tanh$ units, a sigmoid output — on the **XOR** problem, which no
linear model can solve. Each training iteration is decomposed into nine
inspectable phases: the input is loaded; the forward pass computes each
pre-activation $z^{(\ell)}$ and activation $a^{(\ell)}$ in turn; the loss is
formed; the backward pass propagates the errors $\delta^{(\ell)}$ and accumulates
$\partial L/\partial W^{(\ell)}$; and gradient descent updates every parameter.

Pressing **step** advances one phase, and the panel beneath prints the exact
arithmetic — every weight, every product, every gradient — that produced the
values shown on the diagram. **play** runs the phases in sequence; the
**iteration** slider scrubs across all 600 training steps. The heat map at the
right is the network's output $\hat{y}$ over the input square — observe it resolve
from a featureless wash into the XOR checkerboard as the loss curve descends.

<NetworkTrainer client:visible />

Three points merit emphasis. First, the backward pass consumes the activations
the forward pass stored: $\partial L/\partial W^{(2)}_j = \delta^{(2)} a^{(1)}_j$
requires precisely the $a^{(1)}_j$ computed on the way in, which is why a forward
pass must cache its activations. Second, a parameter's gradient is scaled by its
input, so on the example $x = (0, 0)$ every weight feeding the hidden layer
receives zero gradient on that step, while the biases still move. Third, the
update is entirely local: each parameter shifts by $-\eta\,\partial L/\partial
\theta$, and no parameter requires any information beyond its own gradient.

## Verification in code

These claims may be verified directly. The following compact **autograd
engine** — approximately 40 lines — constructs the identical expression. It
computes gradients by chaining local derivatives, after which $\partial L/\partial
w$ is checked against a finite-difference estimate:

<PyCell
	client:only="react"
	id="bp-micrograd"
	title="micrograd.py"
	code={`import math

class Value:
    """A scalar that remembers how it was computed, so it can backprop."""
    def __init__(self, data, _children=()):
        self.data = data
        self.grad = 0.0
        self._backward = lambda: None
        self._prev = set(_children)

    def __add__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data + other.data, (self, other))
        def _backward():
            self.grad += out.grad
            other.grad += out.grad
        out._backward = _backward
        return out

    def __mul__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data * other.data, (self, other))
        def _backward():
            self.grad += other.data * out.grad
            other.grad += self.data * out.grad
        out._backward = _backward
        return out

    def __pow__(self, p):
        out = Value(self.data ** p, (self,))
        def _backward():
            self.grad += (p * self.data ** (p - 1)) * out.grad
        out._backward = _backward
        return out

    def tanh(self):
        t = math.tanh(self.data)
        out = Value(t, (self,))
        def _backward():
            self.grad += (1 - t * t) * out.grad
        out._backward = _backward
        return out

    def __neg__(self):       return self * -1.0
    def __sub__(self, o):    return self + (-o if isinstance(o, Value) else Value(-o))
    def __radd__(self, o):   return self + o
    def __rmul__(self, o):   return self * o

    def backward(self):
        topo, seen = [], set()
        def build(v):
            if v not in seen:
                seen.add(v)
                for c in v._prev:
                    build(c)
                topo.append(v)
        build(self)
        self.grad = 1.0
        for v in reversed(topo):
            v._backward()

# Same expression and inputs as the graph above:
w, x, b, y = Value(0.9), Value(1.0), Value(-0.4), Value(0.5)
n = w * x
q = n + b
a = q.tanh()
L = (a - y) ** 2
L.backward()

print(f"forward:  n={n.data:.3f}  q={q.data:.3f}  a={a.data:.3f}  L={L.data:.4f}")
print(f"grads:    dL/dw={w.grad:.4f}  dL/dx={x.grad:.4f}  dL/db={b.grad:.4f}")

# sanity-check dL/dw against a numerical gradient
L_of = lambda wv: (math.tanh(wv * 1.0 - 0.4) - 0.5) ** 2
num = (L_of(0.9 + 1e-6) - L_of(0.9 - 1e-6)) / 2e-6
print(f"check:    autograd dL/dw={w.grad:.4f}   numeric={num:.4f}  ✓")
`}

## Application at scale

We now scale the construction up. The following **2 → 16 → 1** network is trained
from scratch in NumPy — forward pass, backpropagation, and gradient descent, all
implemented by hand — to separate two interleaving moons. It prints the loss as it
learns, then plots the decision boundary it has found:

<PyCell
	client:only="react"
	id="bp-train-moons"
	title="train_moons.py"
	code={`import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(0)

# --- data: two interleaving moons -----------------------------------------
m = 120
t = np.linspace(0, np.pi, m)
outer = np.c_[np.cos(t), np.sin(t)]
inner = np.c_[1 - np.cos(t), 0.5 - np.sin(t)]
X = np.vstack([outer, inner]) + rng.normal(0, 0.10, (2 * m, 2))
Y = np.r_[np.zeros(m), np.ones(m)].reshape(-1, 1)

# --- a 2-16-1 MLP, initialized small --------------------------------------
sigmoid = lambda z: 1 / (1 + np.exp(-z))
W1 = rng.normal(0, 0.8, (2, 16));  b1 = np.zeros((1, 16))
W2 = rng.normal(0, 0.8, (16, 1));  b2 = np.zeros((1, 1))

lr, losses = 0.6, []
for epoch in range(2500):
    # forward
    a1 = np.tanh(X @ W1 + b1)
    p = sigmoid(a1 @ W2 + b2)
    # binary cross-entropy loss
    loss = -np.mean(Y * np.log(p + 1e-7) + (1 - Y) * np.log(1 - p + 1e-7))
    losses.append(loss)
    # backward (chain rule, vectorized)
    dz2 = (p - Y) / len(X)
    dW2 = a1.T @ dz2;              db2 = dz2.sum(0, keepdims=True)
    dz1 = (dz2 @ W2.T) * (1 - a1 ** 2)
    dW1 = X.T @ dz1;               db1 = dz1.sum(0, keepdims=True)
    # gradient descent
    W1 -= lr * dW1; b1 -= lr * db1; W2 -= lr * dW2; b2 -= lr * db2
    if epoch % 500 == 0:
        print(f"epoch {epoch:4d}   loss {loss:.3f}")

# --- plot decision boundary + loss curve ----------------------------------
fig, (axb, axl) = plt.subplots(1, 2, figsize=(8.2, 3.4))
gx, gy = np.meshgrid(np.linspace(X[:, 0].min() - .5, X[:, 0].max() + .5, 200),
                     np.linspace(X[:, 1].min() - .5, X[:, 1].max() + .5, 200))
grid = np.c_[gx.ravel(), gy.ravel()]
pg = sigmoid(np.tanh(grid @ W1 + b1) @ W2 + b2).reshape(gx.shape)
axb.contourf(gx, gy, pg, levels=20, cmap="RdBu", alpha=0.75)
axb.scatter(X[:, 0], X[:, 1], c=Y.ravel(), cmap="RdBu", edgecolor="k", s=18, lw=0.4)
axb.set_title("decision boundary"); axb.set_xticks([]); axb.set_yticks([])
axl.plot(losses); axl.set_title("training loss"); axl.set_xlabel("epoch"); axl.grid(alpha=0.3)
fig.tight_layout()

acc = ((p > 0.5) == Y).mean()
print(f"final loss {losses[-1]:.3f}   train accuracy {acc:.1%}")
`}
