A scratchpad for extending any experiment. The cells below share **one Python
kernel**: a definition introduced in one cell is available in the next, as in a
notebook. NumPy, Matplotlib, pandas, SciPy, scikit-learn, and SymPy are each
available through a plain `import`; nothing is installed, and no data leaves the
browser.

<Notebook
	client:only="react"
	cells={[
		{
			id: 'welcome',
			title: 'start.py',
			code: `import numpy as np\nimport matplotlib.pyplot as plt\nprint("Python is ready —", "NumPy", np.__version__)`,
		},
		{
			id: 'scratch',
			title: 'scratch.py',
			code: `# Your turn. For example, a quick plot:\nx = np.linspace(0, 4 * np.pi, 400)\nplt.plot(x, np.sin(x) * np.exp(-x / 6))\nplt.title("damped sine"); plt.grid(alpha=0.3)`,
		},
	]}
/>
