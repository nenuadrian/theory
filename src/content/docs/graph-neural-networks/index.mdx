A great deal of data is neither a grid nor a sequence. Molecules, social networks,
road maps, citation graphs, knowledge bases, 3-D meshes, and the call graph of a
program are all **graphs**: a set of entities together with the relationships
between them. A graph neural network performs deep learning on that structure
*directly*, rather than flattening it into a form it does not possess.

The field rests on a single idea — **message passing**: every node repeatedly
incorporates information from its neighbours. By stacking several rounds of this
operation and making the mixing learnable, one can classify nodes, predict missing
links, or assign scores to entire molecules.

## What this track builds

By its conclusion, the reader will have implemented message passing, a complete
**graph convolutional network** (forward pass, backpropagation, and
semi-supervised training, all in NumPy), a **graph attention** layer, and a global
**graph-transformer** layer with a Laplacian positional encoding and a
distance-biased attention. Interactive figures further demonstrate why stacking too
many layers causes every node to converge to the same vector, and how global
attention reaches across a graph that message passing cannot.
